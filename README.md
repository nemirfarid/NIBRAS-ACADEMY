# NIBRAS ACADEMY
**Apprendre • Réussir • Exceller**

Application éducative Android pour les élèves algériens :
- Primaire : 1AP à 5AP
- Moyen : 1AM à 4AM
- Secondaire : 1AS à 3AS, toutes filières
- Français, arabe (RTL) et anglais

Socle initial Flutter : accueil, choix du cycle, choix du niveau et catalogue initial de matières.

Les prochaines étapes ajouteront les contenus pédagogiques vérifiés, cours, vidéos, exercices corrigés, examens, fiches « À retenir par cœur » en PDF, stockage hors ligne et suivi de progression.

Aucun symbole de croix dans l'identité visuelle ou l'interface.
